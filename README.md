# Nick's Notes

A personal repository for storing notes in Markdown format.

## Structure

```
notes/
├── getting-started.md    # Introduction and Markdown basics
└── ...                   # Add your notes here
```

## How to Use

1. Create new notes as `.md` files in the `notes/` directory
2. Organize notes by topic using subdirectories if needed
3. Use Markdown syntax for formatting
4. Commit and push your notes to keep them backed up

## Quick Markdown Reference

- `# Header 1` - Main header
- `## Header 2` - Sub header
- `**bold**` - Bold text
- `*italic*` - Italic text
- `[link](url)` - Links
- `` `code` `` - Inline code
- ` ```language ` - Code blocks
- `- item` - Bullet lists
- `1. item` - Numbered lists
